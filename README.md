# Meu Portfólio Profissional

## Sobre o projeto
Portfólio pessoal desenvolvido como atividade acadêmica do curso de Ciência da Computação.
A página apresenta informações sobre o autor, habilidades, objetivos profissionais e formação acadêmica.

## Tecnologias utilizadas
- HTML5
- CSS3
- Visual Studio Code
- Git e GitHub

## Estrutura do projeto
- `index.html`: página principal do portfólio.
- `README.md`: documentação do projeto.
- `img/perfil.png`: foto de perfil utilizada na página.

## Como visualizar
Abra o arquivo `index.html` em um navegador.
